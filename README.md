# Midas Core Banking Virtual Experience

A simulation project completed as part of the Midas Virtual Experience Program, demonstrating backend development concepts by building and enhancing core banking functionalities using Java and Spring Boot.

## Features

- RESTful API development
- Transaction processing
- Account management operations
- Spring Boot backend implementation
- Unit testing for application reliability

## Tech Stack

**Language:** Java  
**Framework:** Spring Boot  
**Build Tool:** Maven  
**Testing:** JUnit

## Installation

```bash
git clone https://github.com/AsmithaPari-23/forage-midas.git
cd forage-midas
./mvnw spring-boot:run
```
